# 🎯 Интерактивный справочник ОКЗ

Онлайн-справочник по Общероссийскому классификатору занятий (ОК 010-2014, МСКЗ-08). Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/okz/](https://prog815.github.io/okz/)

Этот справочник — для тех, кто подбирает коды занятий для кадрового учёта, статистической отчётности в Росстат, HR-систем, справочников должностей в 1С:ЗУП и SAP, а также для аналитики рынка труда. Главная задача — помочь быстро найти корректный код ОКЗ по названию занятия или по самому коду (с контрольным числом и без) и скопировать его в один клик.

---

## Что кодирует ОКЗ

**ОКЗ** — общероссийский классификатор занятий. Это плоский список, в котором каждая запись — это конкретное занятие (разработчик ПО, бухгалтер, водитель и т.д.).

В текущем снимке справочника содержится **618 записей**. Классификатор разбит на 10 основных групп (разделов) и имеет 4 уровня иерархии.

Каждая карточка содержит:
- **Код** (1, 2, 3 или 4 цифры, ведущие нули не используются).
- **Контрольное число (КЧ)** — пятый знак в официальной форме кода (например, `2512 1`), используется для проверки правильности ввода.
- **Наименование** (например, «Разработчики программного обеспечения»).
- **Уровень иерархии** (Основная группа, Подгруппа, Малая группа, Начальная группа).
- **Раздел** (например, «Специалисты высшего уровня квалификации»).

Справочник предназначен для кадровиков, HR-специалистов, бухгалтеров, аналитиков рынка труда и разработчиков учётных систем.

- сопоставить конкретную должность из штатного расписания с более широким понятием «занятия» ОКЗ.

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются во время ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду — с КЧ и без.** Введите `2512`, `2512 1` или `25121` — справочник распознает любой формат. Код ищется строго с начала строки.
- **Поиск по наименованию.** Одно или несколько слов по логике «И»: `разработчики программного обеспечения`, `водитель автомобиля`.
- **Фильтр по 10 основным группам.** Выпадающий список рядом с поисковой строкой; бейдж раздела в карточке тоже кликабельный и включает фильтр.
- **Плоский список.** Все 618 записей выстроены единым списком, без скрытых уровней. Уровень записи виден в бейдже карточки.
- **Копирование в один клик.** Клик по коду копирует его в буфер обмена; клик по бейджу КЧ копирует только контрольное число. Внизу экрана появится подтверждение.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. В текст автоматически подставляются код, КЧ, раздел и уровень.
- **Прямые ссылки на коды.** Каждый код можно передать коллеге через `?code=…` в адресе (с КЧ и без).
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Как пользоваться

1. **Откройте страницу** — сразу показывается первая порция всех записей в порядке источника (разделы 0–9).
2. **Начните вводить запрос** — код (с КЧ или без) или слово из названия.
3. **Кликните по коду** в карточке — он скопируется в буфер.
4. **Кликните по КЧ** — скопируется контрольное число отдельно.
5. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
6. **Выберите раздел** в выпадающем списке или кликните на бейдж раздела в карточке, чтобы отфильтровать список.

> **Важно про формат кода.** В официальной форме код ОКЗ пишется как `XXXX K`, где `XXXX` — код занятия (1, 2, 3 или 4 цифры), а `K` — контрольное число. Например: `2512 1`. У одноцифровых кодов контрольное число в источнике отсутствует. КЧ не участвует в иерархии и в URL: код `2512` ищется по четырём цифрам, без КЧ.

## Примеры запросов

- `2512` или `2512 1` — Разработчики программного обеспечения.
- `программист` — все занятия, связанные с программированием.
- `бухгалтер` — Бухгалтеры и специалисты по финансам.
- `водитель` — Водители автомобилей, трамваев и т. д.
- `1` — все занятия в разделе «Руководители».
- `2310` — Профессорско-преподавательский персонал.

**Популярные коды:**
- `0` — Военнослужащие;
- `1` — Руководители;
- `2` — Специалисты высшего уровня квалификации;
- `2310 0` — Профессорско-преподавательский персонал университетов;
- `2411 6` — Бухгалтеры;
- `2512 1` — Разработчики программного обеспечения.
